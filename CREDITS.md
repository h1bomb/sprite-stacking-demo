# Credits / 致谢

This repository is an original implementation of a sprite-stacking renderer,
a procedural voxel car, and a four-view slicing tool. The technique and
several implementation details were learned from the work below. Thank you.

本仓库的渲染器、程序化体素小车和四视图切片工具为原创实现。手法与若干实现细节
来自下列公开资料，在此致谢。

## Inspiration and references / 灵感与参考

- **Kimo** ([@asynkimo](https://x.com/asynkimo)) — pixel-art sprite stacking
  demonstrations:
  https://x.com/asynkimo/status/2121716250820964431

- **Rehan Sheikh** ([@rehan_shei](https://x.com/rehan_shei)) — *moon-stack*
  (plain-JS stacked voxel scene on [patch.gg](https://patch.gg/rehan/moon-stack)):
  https://patch.gg/rehan/moon-stack

- **SpriteCook** — *Sprite Stacking Pixel Art* guide (four-view carving,
  draw order, squash, and the Godot snippet this demo follows):
  https://www.spritecook.ai/blog/sprite-stacking-pixel-art

None of those authors' artwork, video, or source code is bundled in this
repository. Please credit them if you share work that builds on their
examples, and check their licenses before reusing their assets.

本仓库不包含上述作者的原画、视频或源代码。如果分享受他们示例启发的作品，请注明来源，
并在复用其素材前自行确认授权。
